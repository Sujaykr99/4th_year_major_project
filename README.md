# 4th_year_major_project

MATRIX - career prediction & roadmap

## Overview

This repository contains a backend (Python) and frontend (React/Vite) for the MATRIX career prediction and roadmap generator.

## Quickstart

Backend (Python)

1. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate  # or `.venv\Scripts\activate` on Windows
```

2. Install dependencies:

```bash
pip install -r backend/requirements.txt
```

3. Run the backend (example):

```bash
cd backend
uvicorn app.main:app --reload
```

Frontend (Node)

1. Install dependencies:

```bash
cd frontend
npm install
```

2. Run the dev server:

```bash
npm run dev
```
